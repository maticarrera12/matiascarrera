## Historia de HTML

HTML (**HyperText Markup Language**) es el lenguaje estándar utilizado para estructurar el contenido de las páginas web.

Fue creado en 1991 por **Tim Berners-Lee** mientras trabajaba en el CERN. Su objetivo era permitir que investigadores compartieran documentos mediante enlaces de hipertexto.

Con el paso de los años surgieron distintas versiones:

* HTML 2.0 (1995)
* HTML 3.2 (1997)
* HTML 4.01 (1999)
* XHTML (2000)
* HTML5 (2014)

Actualmente, **HTML5** es la versión utilizada por todos los navegadores modernos.

## ¿Qué es HTML?

HTML no es un lenguaje de programación.

Es un **lenguaje de marcado**, lo que significa que utiliza etiquetas para describir la estructura del contenido.

Por ejemplo:

```html
<h1>Hola Mundo</h1>
<p>Mi primera página web.</p>
```

El navegador interpreta esas etiquetas y las transforma en elementos visuales.

## Anatomía de un documento HTML

Un documento HTML básico tiene la siguiente estructura:

```html
<!DOCTYPE html>
<html lang="es">
  <head>
    <meta charset="UTF-8" />
    <title>Mi primera página</title>
  </head>
  <body>
    <h1>Bienvenido</h1>
    <p>Este es mi primer documento HTML.</p>
  </body>
</html>
```

## Ejemplo con componente MDX

Si estás utilizando MDX, también podés renderizar componentes directamente dentro del contenido.

```html
<h1>Hola Mundo</h1>
<p>Mi primera página web.</p>
```

## Ventajas de HTML

1. Fácil de aprender.
2. Compatible con todos los navegadores.
3. Base fundamental del desarrollo web.
4. Funciona junto a CSS y JavaScript.

> Todo sitio web comienza con HTML. Luego CSS se encarga de los estilos y JavaScript de la interactividad.

## Resumen

HTML es el lenguaje que define la estructura de una página web. Aprenderlo correctamente es el primer paso para convertirse en desarrollador frontend.
