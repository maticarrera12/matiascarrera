Los documentos HTML tienen una estructura bien definida para que el navegador pueda leerlos, entenderlos y representarlos correctamente.

Podemos tomar un atajo para construirla escribiendo en el editor de código simplemente `!` + <kbd>TAB</kbd>, lo que generará la siguiente estructura:

## Estructura

```html
<!DOCTYPE html> <!-- Tipo de documento -->
<html lang="en">
<head> <!-- Cabecera del documento -->
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
</head>
<body> <!-- Cuerpo del documento -->

</body>
</html>
```

<Warning>

El documento debe ser del tipo `.html` para que el atajo funcione y contar con Emmet habilitado.

</Warning>

## El `<!DOCTYPE html>`

Define, como su nombre lo indica, el tipo de documento. Se escribe en la primera línea del archivo y es obligatorio.

Aunque el navegador intentará interpretar el documento incluso si no está presente, esta declaración le indica que el documento utiliza HTML5.

Si no se especifica, el navegador entra en **Quirks Mode** (*modo no estándar*), activando un modo de retrocompatibilidad pensado para páginas web antiguas.

## Etiqueta `html`

Es la etiqueta raíz del documento y contiene todo el contenido de la página.

En ella suele encontrarse el atributo `lang`, que indica el idioma principal del documento.

```html
<html lang="es">
```

Esto ayuda a los navegadores, lectores de pantalla y motores de búsqueda a interpretar correctamente el contenido.

## Etiqueta `head`

No es una parte visual de la página. Aquí se incluyen los metadatos, es decir, información que el navegador necesita pero que el usuario no ve directamente.

Por ejemplo:

- Título de la página web (*el que aparece en la pestaña del navegador*). **Obligatorio**.
- Descripción de la web (*puede aparecer en los resultados de búsqueda*).
- Miniatura de la web (*cuando se comparte un enlace*).
- Icono de la web (*favicon*).

También es donde se importan o referencian otros archivos externos (`.css`, `.js`, fuentes, etc.).

## Etiqueta `body`

Aquí sí estará todo el contenido visual de nuestra web. Todo el esqueleto de la página estará dentro de `body`.

Es una de las etiquetas más importantes del documento y va justo después de `head`.
