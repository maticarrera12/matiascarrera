## Tipos de errores

Estos son errores que nos podemos encontrar.

| Tipo de error | Descripcion |
|---|---| 
| Sintaxis | Codigo mal escrito, el navegador intentara entender que se quiso decir. |
| Accesibilidad | Si bien esta bien escrito, puede no verse bien en determinados dispositivos, ser inaccesibles para un invidente o similar. |
| Posicionamiento | Los buscadores de Google pueden no favorecer a la pagina en las busquedas. |
| Rendimiento | Cargas lentas, mala optimizacion, imagenes faltantes |
| Usabilidad | La forma en que esta hecho genera friccion con el usuario |

Por el momento solo vamos a hablar del primer tipo.
