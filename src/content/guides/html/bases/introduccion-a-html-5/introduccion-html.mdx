HTML nació en 1991 de la mano de Tim Berners-Lee mientras trabajaba en el CERN. Su objetivo era permitir que los investigadores compartieran documentos mediante enlaces de hipertexto.

```html
<a href="https://www.mcarreradev.com">mcarreradev.com</a>
```

El navegador interpreta esa etiqueta y la transforma en un enlace.

## ¿Qué es HTML?

HTML no es un lenguaje de programación.

Es un **lenguaje de marcado**, lo que significa que utiliza etiquetas para describir la estructura del contenido.

HTML significa **HyperText Markup Language**.

- **HyperText:** texto con enlaces.
- **Markup:** marcado mediante etiquetas.

El navegador interpreta esas etiquetas y las transforma en los elementos que vemos en una página web.

## Ventajas de HTML

1. Es fácil de aprender.
2. Es compatible con todos los navegadores modernos.
3. Es la base fundamental del desarrollo web.
4. Funciona junto con CSS y JavaScript.

<Tip>

<p>Aprender HTML antes que CSS o JavaScript hará que entiendas mucho mejor cómo está construida una página web. Una buena base en HTML facilita el aprendizaje de las demás tecnologías.</p>

## ¿Qué es una etiqueta HTML?

Una etiqueta HTML es un elemento que se utiliza para definir el contenido de una página web. Las etiquetas son la base del lenguaje HTML.

No cualquier palabra es una etiqueta HTML; solo aquellas que tienen un significado especial para el navegador.

Por ejemplo:

```html
<h1>Hola Mundo</h1>
```

`<h1>` es una etiqueta HTML y `Hola Mundo` es el contenido que se mostrará dentro de ella.

## La importancia de la semántica en HTML

A partir de HTML5 se incorporaron etiquetas semánticas cuyo objetivo es describir el significado del contenido. Estas etiquetas no buscan darle un estilo visual a la página, sino aportar estructura y significado.

Antes era muy común utilizar la etiqueta `<div>` para agrupar prácticamente todo el contenido.

Hoy en día existen etiquetas como `<header>`, `<main>` o `<footer>`, que permiten describir mejor la función de cada sección dentro de una página web.

> Todo sitio web comienza con HTML. Luego, CSS se encarga de los estilos y JavaScript de la interactividad.
