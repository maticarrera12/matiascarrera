Las etiquetas HTML son fragmentos de código que indican al navegador cómo interpretar, estructurar y mostrar el contenido de una página web.

## Categorias de etiquetas

Como ya vimos, las etiquetas HTML no son palabras sueltas, sino que tienen un significado especial. Podemos agruparlas en las siguientes categorías:

1. Textuales
2. Agrupación
3. Multimedia
4. Tablas
5. Formularios
6. Interactivas
7. Semánticas
8. Scripting

# Estructura

{/* ![Estructura de una etiqueta HTML](../../assets/images/estructura-etiqueta-html.png) */}

La mayoría de las etiquetas están compuestas por una **etiqueta de apertura**, un **contenido** y una **etiqueta de cierre**. Sin embargo, existen algunas excepciones que veremos más adelante.

Las etiquetas también pueden contener otras etiquetas en su interior.

```html
<div>
    <h1>Hola Mundo</h1>
    <p>Mi primera página web.</p>
</div>
```

# Atributos

Los atributos son propiedades que modifican el comportamiento o aportan información adicional a una etiqueta.

Por ejemplo:

```html
<input type="text" disabled placeholder="Ingrese su nombre">
```

Existen tres tipos de atributos:

- **Conjunto de valores:** aceptan un conjunto de valores específicos.
- **Valores libres:** pueden recibir cualquier valor válido.
- **Atributos booleanos:** no necesitan un valor. Si están presentes, su valor es `true`; si se omiten, se consideran `false`.

El orden de los atributos no afecta el funcionamiento de la etiqueta. Sin embargo, un mismo atributo no debería declararse más de una vez; si ocurre, el navegador utilizará el último valor encontrado.

```html
<video src="video.mp4"></video>
<video controls></video>
<video preload="auto"></video>
```

<Tip>

Es recomendable escribir primero los atributos más importantes, como `src`, `href`, `type` o `id`, y dejar al final los atributos booleanos u opcionales. Aunque el navegador no lo necesita, mejora la legibilidad del código.

</Tip>

# Contenido

El contenido de una etiqueta es todo aquello que se encuentra entre la etiqueta de apertura y la etiqueta de cierre. Es el texto o los elementos que queremos mostrar en la página.

```html
<p>Este es el contenido de la etiqueta.</p>
```
