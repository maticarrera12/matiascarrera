Las etiquetas HTML son fragmentos de código que indican a los navegadores cómo interpretar, estructurar y mostrar el contenido de una página web.

## Se categorizan

Como ya te conte, no son palabras sueltas, sino que tienen un significado especial. Las podemos dividir en:

1. Textuales
2. Agrupacion
3. Multimedia
4. Tablas
5. Formularios
6. Interactivas
7. Semánticas
8. Scripting

# Estructura
{/* ![Estructura de una etiqueta HTML](../../assets/images/estructura-etiqueta-html.png) */}

Tiene una etiqueta de apertura y en general tienen una etiqueta de cierre. Pero ya veremos que hay etiquetas que no tienen cierre.

Pueden incluir dentro de ellas otras etiquetas.

```html
<div>
    <h1>Hola Mundo</h1>
    <p>Mi primera página web.</p>
</div>
```

<Warning>

Las etiquetas no se pueden anidar una dentro de la otra.

</Warning>

# Atributos

Los atributos son palabras que se utilizan para modificar el comportamiento de la etiqueta.

Por ejemplo:

```html
<input type="text" disabled placeholder="Ingrese su nombre">
```

Hay 3 tipos de atributos: 
- Conjunto de valores: Con valores especifcos.
- Valores libres: Solo un valor.
- Atributos booleanos: No tienen valor. Omitidos se consideran <code>false</code> , si se nombran se consideran <code>true</code> 

El orden de los atributos no importa, pero si el nombre del atributo y el valor. Si se declara varias veces se toma el último.

```html
<video src="video.mp4"></video>
<video controls></video>
<video preload="auto"></video>
```

# Contenido 

El contenido de una etiqueta es lo que se encuentra entre la etiqueta de apertura y la etiqueta de cierre. Es lo que queremos que se muestre en la página.
