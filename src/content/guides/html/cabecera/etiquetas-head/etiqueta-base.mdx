Nos sirve para establecer una ruta base para enlaces relativos.

## La etiqueta `base`

Breve resumen de enlaces e hipervínculos:

| Atributo | Descripción |
|---|---|
| `href` | Establece la ruta base para los enlaces relativos del documento HTML |
| `target` | Establece el destino para los enlaces relativos del documento HTML |

Supongamos que estamos en esta web: `https://mcarreradev.com`

```html
<head>
    <title>Sin base</title>
</head>
<body>
    <a href="blog">Blog</a>
    <a href="guides">Guías</a>
</body>
```

1. El primer enlace nos lleva a `https://mcarreradev.com/blog`
2. El segundo enlace nos lleva a `https://mcarreradev.com/guides`

Con una etiqueta `base` en los enlaces se añade la URL indicada.

### Ejemplo con `base`

```html
<head>
    <title>Con base</title>
    <base href="https://mcarreradev.com/guides" target="_blank">
</head>
<body>
    <a href="html">HTML</a>
    <a href="css">CSS</a>
</body>
```

Ahora, por más que nos encontremos en `https://mcarreradev.com`, al haber fijado la URL base, nos llevará a:

1. El primer enlace hacia `https://mcarreradev.com/guides/html`
2. El segundo enlace hacia `https://mcarreradev.com/guides/css`

<Warning title="Solo se aplica la primera">

Si el documento tiene más de una etiqueta `base`, el navegador solo tiene en cuenta la primera y descarta las demás.

</Warning>

## Ejercicios del modulo

1. `title`

Estás desarrollando tu portfolio, tenés que escribir un title que cumpla con las buenas prácticas:

- No debe estar vacío.
- Debe describir correctamente el contenido de la página.
- Debe tener entre 50 y 60 caracteres aproximadamente.
- No debe repetir palabras innecesariamente.
- Debe resultar útil para un usuario que lo vea en una pestaña del navegador o en un buscador.

2. `base`

Tenés el siguiente código:

```html
<body>
    <a href="blog.html">Blog</a>

    <a href="contacto.html">Contacto</a>

    <img src="logo.png" alt="Logo">
</body>
```
Querés que todos los enlaces e imágenes del documento usen tu dominio como ruta base: 

`https://tudominio.dev/`

No podés modificar las etiquetas de `body`.

- Extra: ¿cómo harías para que se abra en otra ventana?

<Reveal type="solution">

```html
<head>
    <base href="https://mcarreradev.dev/">
</head>
<body>
    <a href="blog.html">Blog</a>

    <a href="contacto.html">Contacto</a>

    <img src="logo.png" alt="Logo">
</body>
```

</Reveal>
