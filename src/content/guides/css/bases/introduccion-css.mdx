CSS nacio en 1994 por Håkon Wium Lie y Bert Bos mientras trabajaban en el CERN. Su objetivo era permitir que investigadores compartieran documentos mediante enlaces de hipertexto.


## ¿Qué es CSS?

CSS viene de **Cascading Style Sheets**.

Es un lenguaje de programación que se utiliza para definir el estilo de una página web.
